# kintone App Toolkit 2.3.0

無料の設定確認・比較から、AIによる相談・業務理解・アプリ開発へ進めるようになりました。

## 無料で使える機能

- **Config Lens**：運用環境と動作テスト環境の設定を比較。フォーム配置も確認できます。
- **設定と依存関係の確認**：フィールド・一覧・通知・権限・プロセス・JavaScript・プラグインを整理します。
- **Customize / JS Scanner**：フィールドやイベントを起点にコードを調べ、変更の影響を確認できます。
- **表示の改善**：ライト／ダークの配色を統一し、最小化バーにも丸みを付けました。

## AIで相談・開発

取得したアプリ設定と既存JavaScriptを相談内容に添え、現在の構成に合う説明や変更案を作ります。

- アプリ診断：不整合や改善の候補を整理。1回3クレジット。
- 業務工程の読み解き：全体図と、各工程の担当・入力・通知・根拠を整理。1回10クレジット。
- 資料作成：概要・仕様・操作説明・引継ぎ・変更内容を目的別に作成。1回2クレジット。
- フィールド追加・条件設定・JavaScript生成などの相談と、変更案の確認。通常相談1、最終案作成3クレジット。

会員登録の初回10クレジットは一度限り・有効期限なし・支払い情報不要です。継続利用のプランは[Toolkitの料金・利用案内](https://www.nestrec.com/toolkit)をご覧ください。無料の設定確認にAI契約は不要です。

## 会話を続きから

会話・資料・下書き・編集中コードをブラウザーに自動保存します。同じ利用者・ドメインの全アプリで20 MiBが上限です。完了した会話は30日後に整理し、作業中と「残す」を選んだ会話は保護します。別端末との同期はありません。必要な内容はファイルにも保存してください。

通信が切れた場合は、保存済みのAI回答を追加消費せず回収できます。回収可能期間は30日です。

## 更新と確認

既存のTampermonkeyスクリプトを更新し、kintoneアプリを再読み込みしてください。更新前に作業中の会話をファイル保存することをおすすめします。

設定の事実とAIの推測は区別して表示します。取得できない設定、実際の運用、JavaScriptやプラグインの動作は別途確認が必要です。AIへ相談しただけで設定は変わりません。AIの変更案は内容を確認して動作テスト環境で試してください。
