# Toolkit 2.3.0 リリースノート

状態：公開候補（未公開）。公開済みの2.2.6とは区別しています。

## 今回変わること

「AI Assistant」（旧「開発支援」）で、アプリの説明や変更案を見ながら相談を続けられるようになります。

- 会話・採用内容・資料・作成したJavaScript・未送信文・手元の編集をブラウザーへ自動保存し、同じアプリでAI Assistantを開くと最後の続きが自動で戻ります。別の会話は［保存した会話］から選べます。［完了にする］から30日後に整理し、作業中と［残す］は保護します。保存枠は同じブラウザー内の同じドメイン・利用者の全アプリ・環境で20 MiB。社員間共有・端末間同期・サーバー保存は含みません。容量不足で未保存になった場合は知らせ、期限内の履歴を勝手に削除しません。再開だけではAIや反映を実行しません。Toolkit 9242538を検証タブへ導入し、未送信文と手元コードが保存操作・履歴選択なしで戻ることを確認済みです。実AI会話や生成成果物を伴う復旧、期限切れ・容量不足・複数タブ競合は固定データ試験の範囲です。

- 独立したConfig Lensタブで、現在の運用環境を左、動作テスト環境または保存ファイルを右に並べて無料で比較できます。AI Assistantの［未反映の変更を見る］もこのタブを開きます。追加・変更・削除は左から右への違いです。比較できない範囲と手元の未登録編集を分け、環境間の比較だけ任意でAIへ説明を依頼できます。
- 通常タブとAI Assistantの配色・文字・操作ボタンを揃え、ライト／ダークのどちらでも読みやすくしました。タブの選択状態は控えめな背景と下線で示します。

- Customizeは左にエディター、右にファイル選択と依存関係を配置します。エディターは表示領域の残りの高さを使い、左右の幅を調整できます。右上の操作とファイル選択はコンパクトにまとめています。フィールドコードの入力・選択に合わせて他のJavaScriptや計算式からの参照を確認でき、取得済みのイベント名にカーソルを置くだけで、同じイベントを登録しているJavaScriptへ表示が切り替わります。Field Scannerの表示名はJS Scannerに変更しました。依存関係は登録済みJavaScriptを開くと自動取得し、有効な間はファイルやカーソルの移動で再取得しません。動作テスト環境の設定と登録済みコードを使い、手元の編集は含みません。必要なときは［依存関係を更新］で取り直せます。［AIに相談］で同じ会話のAI Assistantへ移り、修正案・差分と反映はそこで確認します。移動だけではAIを呼ばず、手編集や未送信文も保持します。手編集の登録は右上の操作から内容を確認して行えます。動作テスト環境への登録と、アプリの未反映変更全体を運用環境へ反映するデプロイは、別の操作・別の確認にしました。
- JS Scannerにイベント起点の表示を追加しました。イベント名の検索・選択で使用しているJavaScriptを確認し、ファイルの詳細へ移れます。既存の解析結果を使い、PC／モバイル・登録の記述・登録の候補・未解析のファイルを区別します。
- Deps、JS Scanner、Customizeでフィールドやイベントを選び、［変更の影響をAIに相談］から同じAI Assistantへ移れるようになりました。送信時に動作テスト環境の設定と登録済みコードを取得し、変更範囲・修正順序・未確認事項・修正後の確認項目を整理します。選択・移動だけではAIを呼ばず、手元の編集は送信しません。参照候補と確認済みの設定を分け、相談だけでは採用・反映を始めません。
- Pluginsの状態・差分・ログ・一覧を共通テーマの配色に揃え、タブ内のスタイルが他の画面へ影響しないようにしました。追加・反映ボタンの大きさと余白もCustomizeに揃え、［動作テスト環境に追加］［運用環境へ反映］に統一しています。

- 左に相談と入力欄、右に説明・現在の変更案・進み具合・反映結果を表示します。狭い画面では縦に並びます。
- 相談欄の「アプリの相談／資料の作成・修正」の選択欄をなくしました。そのまま質問や変更内容を入力できます。資料は［資料を作る］から始め、続く修正は同じ相談欄で行えます。
- ［資料を作る］で概要・仕様書・操作説明・引継ぎ・変更内容の5種類から選べます。希望を任意で追記し、作成後も同じ相談で調整できます。選択だけではAIを呼ばず、入力途中の相談文は保持します。
- 「このアプリの仕組みを教えてください」と質問し、続けて同じ相談から引継ぎ資料にまとめられます。本文・表・根拠を確認し、作成済みの内容を追加のAI呼び出しなしでコピー・Markdown保存できます。
- 資料や変更提案にも、同じ動作テスト環境の設定と登録済みコードから調べた依存関係を渡します。古い結果や別環境の情報を混ぜず、取得できなかった範囲は未確認として残します。
- 説明では現在の設定、採用済みで未反映の案、反映結果、未確認のことを区別します。説明だけで変更案の作成・反映は始めず、既存の採用案は保持します。［説明］［変更案］を切り替えられ、以前の説明もページ内の履歴から読めます。
- Customizeはファイル名の横で、取得時の本文と手元の編集の違いを示します。保存・登録・運用環境への反映の違いを必要時に確認でき、依存関係の計算式は開いて読めます。
- 小さい画面で文字を拡大したときも相談欄が極端に狭くならないよう、短い画面では見出しからスクロールできます。
- 返答を待つ間は動く印を表示し、提案・反映前の確認・結果は見出しと並べ方で区別します。
- 停止や接続の通知は「アプリの相談」の横に短くまとめ、理由と次の操作は必要なときに開けます。反映前の確認事項や制約は変更案に残します。
- AIは、変更内容の前提や依存関係に沿った順序で案を作ります。修正してから採用した内容を、計画とJavaScriptの作成へ引き継ぎます。
- 新しいフィールドは追加位置まで提案します。配置の指定がなければ質問し、回答や修正した位置を最終案へ引き継ぎます。既存項目の左右・上下や既存グループ内へ配置できます。
- 選択肢の変更・削除、フィールド削除、計算式の変更と、関連するJavaScriptの修正をまとめて相談できます。参照を外すJavaScriptの登録が必要な場合は、登録を確認してからフィールドを削除します。
- 関連する任意の提案は、依頼された変更と分けて表示します。チェックで選び、［選んだ内容で案を更新］でまとめて取り込めます。チェックだけではAIを呼ばず、未選択の提案は採用内容に含めません。
- 複数の質問に回答した後でも、一部だけを訂正・取り消せます。関係のない回答は保持し、採用した内容を計画と保存資料へ引き継ぎます。修正の送信に失敗・中断した場合、更新前の案では作成できません。
- 保存する資料には、修正後に採用した内容を残し、以前の条件や相談の履歴と区別します。
- 通常の画面では、変更する内容、判断に必要な制約、次の操作を中心に表示します。コードや検査の内訳は必要なときに開けます。
- ［この案で作成］と［動作テスト環境に反映］を分けます。相談や案の修正だけではkintoneの設定を変更しません。
- 反映や復元の結果が不明なときは、現在の設定と登録済みJavaScriptを読み取りだけで再確認できます。確認できない範囲や別の変更は成功扱いにせず、同じ書き込みを自動で再送しません。
- 作成途中・検証不一致・検証できない状態を分け、次の操作を示します。検証できない理由が残る場合に、同じコードの再作成へ一律に誘導しません。
- 計画時に決めた重要な対象・条件・動作を、反映前の「計画で決めたこと」で確認できます。
- 元に戻す途中でJavaScriptの復元だけが完了した場合、その結果を保持し、残った設定の復元へ進めるようにします。再度の確認では対象の反映と現在の設定を照合します。

対象は今回のAIによる開発支援機能です。Health、フィールドや一覧の調査は継続して利用できます。資料の入口を［資料を作る］に統一します。取得済みの設定を決まった形式でまとめる既存の無料機能は、同じ入口の［AIを使わずに書き出す］→［設定資料を書き出す］で利用できます。

## 更新前に

1. 進行中の作成・反映・元に戻す操作を終え、必要な会話、コード、反映結果を手元に残してください。
2. 保存機能のない旧版から更新する場合、ページ内の会話・反映記録は再読み込みで失われます。先に必要な資料やコードを保存してください。保存対応版では［保存済み］を確認します。開き直した過去の反映結果は読み取り専用で、以前の承認や復元操作は再開しません。重要な成果物はファイルでも残してください。会話JSON・Markdownの再取込機能は今回含みません。
3. 同じブラウザーのユーザースクリプトを更新すると、そのブラウザーで開く対象のkintoneアプリにも新版が使われます。

公開時は、対応する模擬テスト環境 → AIサービス（Gateway）→ Toolkitの順で、変更のある部品を更新します。変更のない部品は同じ内容であることを照合して引き継ぎます。未対応のAIサービスには相談を送信しません。説明・資料・任意提案の選択はstagingで確認済みです。見た目の統一はローカルの無料ブラウザーテストに加え、修正版を入れたEdgeの実際の画面でも確認しました。実画面ではダーク表示の通常タブ・AI Assistant・資料作成ダイアログと、全画面／パネル表示を確認し、新しいAIの返答は作成していません。一般公開はまだ行っていません。利用手順は[AI Assistantのガイド](release-workspace.md)を参照してください。

## 確認範囲

変更影響相談は、Toolkit d70452eとstagingで1会話を確認しました。Depsのフィールドから相談し、続けてJS Scannerのイベントから質問すると、計算式・JavaScriptの変更範囲、修正順序、未確認事項、修正後の確認項目が整理されました。移動だけでAIを呼ばないこと、説明の切り替えと本文のコピーも確認しました。この会話では変更の採用・反映は行っていません。Customizeの入口や編集中コード・未送信文の保持は固定応答のブラウザー試験で確認し、今回の実画面確認とは分けています。

今回追加した説明・資料化は、ローカルの固定応答とブラウザー試験で確認しました。概要の質問から引継ぎ資料への書き直し、本文・表・根拠と未確認事項、コピー・保存、説明履歴、変更案との切り替えを対象としています。コピー・保存でAIを呼ばないことや、切り替えで反映前の準備を変えないことも確認しました。概要質問→引継ぎ資料→コピー・保存は57cccb0で実際のAIと画面でも確認しました。テンプレートからの概要・引継ぎ資料の作成とコピー・保存も、実際のAIと画面で確認済みです。

実AIの会話では、PCからモバイルへの対象追加と、承認の流れの変更を含む相談を確認しました。検証専用アプリで、経理確認を通る承認の流れと、PC・モバイルWeb画面での編集可否を確認しています。会話欄の配置変更は、実際のEdge画面でも確認しています。

フィールドの配置は、配置を質問する会話と、「請求書番号」を「備考」のすぐ上へ追加して空欄保存する操作を確認しました。選択肢・計算式・JavaScriptの変更と紹介経路の削除は、検証専用アプリの動作テスト環境で確認しています。外部クライアントの実コードや業務データでの試験ではありません。復元修正は固定データによる無料の試験で確認しました。候補版を実際のアプリへ更新しての復元は未確認です。PC上のモバイルWeb画面での確認と、実スマートフォン端末やkintoneのモバイルアプリでの確認は区別します。

追加前の4e9e0e6では、複数の質問への回答後に配置を訂正し、一覧追加だけを取り消す実AIの会話を確認しました。採用内容と保存資料が一致し、検証専用アプリの動作テスト環境で、訂正した位置への「確認メモ」の追加、空欄保存、取り消した一覧が追加されていないことを確認しています。過去の条件は相談の履歴として残ります。

新しい日付フィールドと任意の一覧追加も、反映前の確認と動作テスト環境への反映まで確認しました。「確認期限」の指定位置・空欄保存・期限の早い順を確認し、未選択のリマインダーは追加されませんでした。

選択肢変更・フィールド削除では、入力済みの値まで戻せる保証がないため、一括の自動復元は提供しません。必要なデータを事前に保管し、反映前の注意を確認してください。

コードの検査と模擬テストの通過は、すべての業務条件での動作保証ではありません。反映後は動作テスト環境で確認してください。AI Assistantから運用環境へは反映しません。kintoneのアプリ設定やCustomize・Pluginsの［運用環境へ反映］は別操作で、そのアプリの未反映変更全体が対象です。

## 初回リリースのプランと利用クレジット

スターターは月額1,480円（税込）・月100クレジット、スタンダードは月額2,980円（税込）・月250クレジットです。相談・仮案の作成や修正は1、資料の作成や修正は2、最終案の作成は一式3クレジットです。最終案は設定だけでもJavaScript込みでも同額で、JavaScriptの本数による追加消費はありません。

最終案は計画ができた時点で3クレジットが確定し、同じ案のコード作成・内部修復・確認では追加消費しません。内容を変えて作り直す場合は別の作成です。閲覧・選択・コピー・保存・自動復旧・無料の設定比較・反映・元に戻す操作そのものは0クレジットです。

対応するAIサービスの残数・確保中・必要クレジットを画面に表示します。資料と最終案で必要残数が異なり、残数不足でも会話・成果物・手元の編集を保持します。同じ案の未完了部分を再開できる場合は、残数0でも追加消費しません。旧サービスの表示を新方式として案内しないよう区別します。

新しい課金方法はローカルの候補で、正式な商品登録・契約適用・配備・公開はしていません。公開前に接続画面、料金ページ、正式契約での動作を照合します。正式な接続手順や途中加入・変更・解約などの未決条件は引き続き残ります。

## Config Lensタブ（公開候補・比較と保存を検証タブで確認済み）

- 左は現在の運用環境に固定し、右の［比較相手］で動作テスト環境／保存ファイルを選びます。カテゴリ別に、左から右への追加・変更・削除を確認できます。両側のアプリと取得日時を常時表示します。
- 選んだ環境の取得済み設定をJSONで保存できます。未取得範囲を記録し、ファイル本体やレコードを含む完全バックアップとは区別します。復元機能は含みません。
- 比較・保存にはAI接続が不要です。環境間の比較だけ、必要なときにAI Assistantへ説明を依頼できます。会話、採用内容、手元の編集は保持します。AI説明の実AI確認は未実施で、固定応答試験と区別します。
- ［比較相手］を［保存ファイル］にしてToolkitの設定JSONを選ぶと、現在の運用環境と比較できます。保存元の環境、設定の取得日時、ファイル保存日時を区別します。別アプリでは一覧等を一意の同名項目で対応づけます。比較相手を切り替えてもファイルを保持し、別画面へ移る操作は不要です。
- 未取得項目は削除と扱わず、JavaScript等は登録情報と本文未確認を区別します。ファイル比較に復元・反映・AI説明は含めません。通常の環境間比較のAI説明は維持します。
