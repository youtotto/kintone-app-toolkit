# kintone App Toolkit 2.3.5

2026年11月15日

## 変更内容

- **確認事項への回答をまとめて送信。** 質問への回答、選んだ追加提案、相談欄の文を一回の相談として送れます。回答の選択だけではAIを呼びません。
- **入力欄を広く、広げた状態を維持。** 会話本文の表示領域を狭めずに入力欄を広げ、入力や回答の更新で手動調整した高さが元に戻る問題を修正しました。
- **入力途中の文を保持。** 画面の切替や更新で下書きを失わず、送信済みの文は会話に残します。通信が失敗・中断したときも、送信済みの文を入力欄へ戻して次の下書きを上書きしません。
- **完成した回答を保持。** 長い説明や複数の条件・質問・選択肢を、文字数や件数だけで途中から削らず、表示・保存復元・次の相談へ引き継ぎます。
- **フィールドの配置とテーブル列の追加を改善。** 既存の項目やグループを基準に追加位置を確認し、テーブル内にも列を追加できます。必要な項目の追加を確認してから、その項目を使うJavaScriptを登録します。
- **自動確認できないという理由だけで作業を止めない。** 作成済みのコードを保持し、内容を確認して動作テスト環境への反映へ進めます。構文エラー、必要な項目の不足、登録先や元コードの変更など、具体的な問題がある場合は反映を止めます。
- **案内を利用者に必要な内容へ整理。** 内部エラーや処理の詳細を通常画面へ出さず、接続の確認、保存容量、作成が残っている内容など、次の操作に必要な案内を表示します。
- **暗いテーマのプロセス矢印を見やすく。** Healthのプロセスフロー図で、線と矢印の先端を背景から見分けやすくしました。
- **Chrome・Edge用の拡張機能ZIPを配布。** Tampermonkey用ユーザースクリプトと同じソースから作る拡張機能を、GitHub Releaseに同梱します。

通常相談の回答が出力上限で途中終了する問題へのサーバー側の修正は、今回の配布に先立って反映済みです。2.3.5では、受け取った回答を画面・保存・次の相談で保持する改善を配布します。

料金・クレジット・契約条件は変更していません。設定の反映には利用者の操作が必要です。AI機能から運用環境へ直接反映することはありません。

## 更新方法

### Tampermonkey版

1. 必要な会話・編集中コードをファイルへ保存します。
2. [公開スクリプト](https://raw.githubusercontent.com/youtotto/kintone-app-toolkit/main/kintoneAppToolkit.user.js)を開き、Tampermonkeyで更新します。
3. kintoneアプリを再読み込みし、Toolkitの表示が「Ver 2.3.5」になっていることを確認してください。

### Chrome・Edge用拡張機能版

[2.3.5の拡張機能ZIP](https://github.com/youtotto/kintone-app-toolkit/releases/download/v2.3.5/kintone-app-toolkit-2.3.5-chrome-extension.zip)を展開し、[拡張機能版の導入・更新手順](../extension/README.md)に沿って読み込みます。Tampermonkey版と同時に有効にしないでください。

Chromeウェブストアの公開は、GitHubでのZIP配布とは別の審査対象です。このリリースはストアでの公開完了を案内するものではありません。

## 検証範囲

無料の自動テストは141ファイルすべて通過しました。ユーザースクリプト版・拡張機能版本体はそれぞれ2,011件が成功し、失敗・時間切れは0件、全141ファイルで同じ結果でした。ビルドと版番号の整合性、配布ZIPの内容も確認しています。

事前の実機動画では、Edgeに読み込んだ拡張機能版で、相談、不足しているテーブル列の追加提案、回答の一括送信、PC用の既存JavaScriptの修正とモバイル用コードの生成、動作テスト環境への反映までを確認しています。PCでは理由・経路の入力漏れで保存を止め、入力後に保存できることも確認しました。

今回の公開では、この確認実績を引き継ぎます。2.3.5へ版を更新した配布物で新たな実AI呼び出し・実機試験は行っていません。モバイル画面での動作は未確認です。拡張機能を実際にインストールする確認と、同一ソースを使った無料の自動テストも区別します。
