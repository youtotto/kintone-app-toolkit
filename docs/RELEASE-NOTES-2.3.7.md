# kintone App Toolkit 2.3.7

2026年11月16日

## 修正内容

- **他アプリ参照の保存結果をユーザー別に分離。** 同じブラウザーで別のkintoneユーザーにログインしたとき、前のユーザーが取得した参照元アプリ名・フィールド情報を表示しないようにしました。以前の共通キャッシュは引き継がないため、必要な場合はRelationsで再走査してください。
- **Pluginsの管理者判定を修正。** kintoneシステム管理者であることを確認できた場合だけ操作画面を表示します。権限情報を取得できない場合も操作を止めます。
- **参照走査の未確認範囲を表示。** アプリアクションの取得に失敗した場合、取得できた参照情報を残しつつ、未確認の件数を表示します。フィールドの変更影響や設定資料にも注意を引き継ぎます。
- **500件上限の警告を修正。** 取得した一覧に自アプリが含まれる場合も、走査を上限で打ち切ったことを表示します。
- **プラグイン選択を修正。** チェックボックス本体だけでなく、プラグイン名・説明・行の余白をクリックして選択できます。キーボードのSpaceキーでも切り替えられます。

料金・クレジット・契約条件・ブラウザー拡張機能の権限は変更していません。

## 更新方法

必要な会話・編集中コードを保存してから更新し、kintoneアプリの一覧画面を再読み込みしてください。表示版は「Ver 2.3.7」です。

- Tampermonkey版：[公開スクリプト](https://raw.githubusercontent.com/youtotto/kintone-app-toolkit/main/kintoneAppToolkit.user.js)を開いて更新します。
- Chrome・Edge用拡張機能版：[2.3.7のZIP](https://github.com/youtotto/kintone-app-toolkit/releases/download/v2.3.7/kintone-app-toolkit-2.3.7-chrome-extension.zip)を取得し、[導入・更新手順](../extension/README.md)に沿って既存フォルダーの内容を置き換え、拡張機能を再読み込みします。ZIP手動導入版は自動更新されません。

更新後も、Tampermonkey版と拡張機能版のどちらか一方だけを有効にしてください。拡張機能版を使う場合、Tampermonkeyの「kintone App Toolkit」スクリプトだけをOFFにします。kintoneアプリを再読み込みし、**「Ver 2.3.7」とToolkitのパネルが1つだけであること**を確認してください。[導入・更新の確認手順](getting-started.md#更新するとき)

Chromeウェブストアの2.3.5提出はそのまま維持します。今回のGitHub公開で審査の取り消しや2.3.7のストア提出は行いません。

## 検証範囲

- 修正前に失敗することを確認した回帰テスト11件が、修正後にすべて成功しました。ログイン切替、権限情報の取得失敗、部分取得、件数上限、名前・余白・キーボードによる選択を含みます。
- 最終配布版は、ユーザースクリプトと拡張機能本体でそれぞれ2,024件が成功し、全143テストファイルで結果が一致しました。失敗・時間切れは0件です。
- 隔離したブラウザーと模擬APIを使用し、実kintoneへの書き込みや有料AI呼び出しは行っていません。実テナントの複数ユーザー切替とモバイル実機は今回の確認範囲外です。
- AIへの相談・生成・反映など変更のない経路は、[2.3.6](RELEASE-NOTES-2.3.6.md#検証範囲)までの検証結果を引き継ぎます。
