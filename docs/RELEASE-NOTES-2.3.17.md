# kintone App Toolkit 2.3.17

2026年11月26日

動作テスト環境で既存の表形式一覧1件に反映した変更を、アプリを開き直した後も取り消せるようになりました。同じブラウザーで［AI Assistant］→［これまでの反映］から対象を開き、［この反映の変更を戻す］を押します。戻す内容を確認したら、［反映前の状態に戻す］を押してください。

反映後に別の一覧などの設定が保存されている場合は、取り消しを止めて理由を表示します。この機能は2.3.17以降で反映し、必要な復元情報を保存できた履歴が対象です。

## 検証範囲

ステージングの受注受付アプリで、ページを再読み込みして反映履歴から取り消すと、元の並び順に戻ることを確認しました。反映後に別の一覧設定を保存したケースでは、取り消しが無効になり、双方の設定が保持されました。
