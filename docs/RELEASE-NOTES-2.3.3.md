# kintone App Toolkit 2.3.3

2026年11月11日

## 修正内容

- 自動検証できない条件があっても、元の要件を維持してJavaScriptを生成するようにしました。
- 生成したコードと説明、未確認の理由を表示し、コピー・ファイル保存・会話からの復元ができます。
- 一部のコードが未確認でも後続の作成を続け、通信断からの再開時には作成済みコードを再生成しません。
- 暗いテーマで前工程・次工程のカードが白くなり、文字を読みにくかった問題を修正しました。

自動確認ができないことを、コードの誤りや検証済みとは扱いません。未確認のコードは、内容と動作を確認してから利用してください。

## 更新方法

会話の保存が完了していることを確認し、Tampermonkeyで更新してアプリを再読み込みしてください。表示が「Ver 2.3.3」になれば更新済みです。

料金・クレジット・契約条件の変更はありません。

## ソース一式に含む改善

- 通知・プロセス・アクセス権・取得済みJavaScript・プラグイン名を横断し、業務工程の概要図と工程別の入力・通知・確認事項を整理します。取得状態、設定の事実と推測、未確認の範囲を区別します。
- 業務工程の確認結果・下書きを保存復元し、アプリの変更相談へ引き継げます。大きな設定の送信では、根拠を保ちながら重複を減らします。
- Config Lensでフォーム配置を表示し、倍率変更と対応位置の強調ができます。比較対象のカードと取得情報をコンパクトに表示します。
- 会話の復元中の空保存を防ぎ、通信断後は保存済み回答を追加生成・追加消費なしで回収できます。
- 一般配布から検証専用の接続切替・費用上限入力を除き、Nest Rec会員接続を使います。初回10クレジットと月間枠を区別して表示します。[2.3.2での接続整理](RELEASE-NOTES-2.3.2.md)も含みます。

## 2026年11月13日のローカル整備

- ビルド処理でKT_BUILDを配布・表示の版に合わせます。@version、SCRIPT_VERSION、リリースノートの不一致を拒否し、再発防止テストと[版の更新手順](versioning.md)を追加しました。
- 生成継続と固定接続先の仕様にテストを合わせ、未確認コードの保持、再生成・反映の防止を確認しました。
- ソース・テスト・ビルド設定を正規フォルダーに集約しました。別管理のAIリポジトリを使う結合テストは[テスト準備](test-setup.md)に従って参照先を指定します。

このローカル整備では実AI・kintoneの実機操作・push・公開は行っていません。これまでの実機確認と今回の無料テストを区別してください。
