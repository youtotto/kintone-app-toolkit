## 接続と送信への同意

新画面の［接続］→［接続を確認する］で、接続先 URL を読める。［接続を更新］は保存された接続を使って health を取り直す。接続先が staging であることは、更新前後それぞれ実際の画面で確認する。

最初に依頼を送るときは、送信への同意 `release-raw-source-1` を確認する。依頼文、アプリの設定、登録済み JavaScript の本文を送ること、レコードの値・添付ファイル・認証情報は送らないことを示す。以前の同意だけで、この新しい同意を済ませた扱いにはしない。今回の準備では依頼の送信や同意の操作をしていない。
