# kintone App Toolkit 2.3.15

2026年11月25日

雑談で最初の返答を受けたあと、好きなタイミングで［アプリの相談へ］を押せるようになりました。会話で整理した困りごとや条件を、通常の相談の下書きに引き継げます。

- 最初の困りごと、利用者の補足、AIの返答を話者が分かる形で残します。AIの発言には「未採用」と表示します。
- 下書きを編集してから送信できます。長い会話は、相談欄の2,000文字の上限に合わせて最初の困りごとと直近の利用者発言を優先し、抜粋と表示します。

## 検証範囲

ステージングの商品台帳で、最初の1往復からの移動と、保存済みの4往復の会話を開いて全8発言が相談の下書きに入ることを確認しました。
