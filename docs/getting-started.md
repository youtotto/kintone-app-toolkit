# はじめてのToolkit：導入から最初の相談まで

まずは無料でアプリの設定を確認し、必要なときにAIへ接続します。無料機能にはNest Recの会員登録もAPIキーも不要です。

## 1. 使うブラウザーに導入する

PCと、利用できるkintone環境を用意してください。ToolkitはkintoneへプラグインZIPを登録する方式ではありません。

**先に、拡張機能版かTampermonkey版のどちらか一方を選びます。** 両方の導入は不要です。すでに使っている場合は、その版の[更新手順](#更新するとき)へ進んでください。

| 導入方法 | 手順 |
| --- | --- |
| Tampermonkey版 | [Tampermonkey公式サイト](https://www.tampermonkey.net/)からブラウザーへ追加し、[公開スクリプト](https://raw.githubusercontent.com/youtotto/kintone-app-toolkit/main/kintoneAppToolkit.user.js)を開いてインストールします。 |
| Chrome・Edge用ZIP版 | [正式Release](https://github.com/youtotto/kintone-app-toolkit/releases/latest)の拡張機能ZIPを取得し、[拡張機能版の手順](../extension/README.md#zipから導入する)に沿って読み込みます。 |

**どちらか一方だけを有効にしてください。** ZIP版の公開とChromeウェブストアの公開は別です。ストアの公開を確認できるまでは、上記の配布先を利用してください。

両方を導入済みの場合、拡張機能版を使うならTampermonkeyの一覧で「kintone App Toolkit」スクリプトだけをOFFにします。Tampermonkey版を使うならブラウザーの拡張機能一覧で「kintone App Toolkit」をOFFにします。他のスクリプトのために使っているTampermonkey全体を無効にする必要はありません。

## 2. アプリの一覧画面で、無料機能を試す

1. 調べたいkintoneアプリの**レコード一覧画面**を開きます。アプリ設定画面や個別レコードの詳細画面ではありません。
2. Toolkitのパネルを開き、見出しが「Ver 2.3.17」で、パネルが1つだけ表示されることを確認します。
3. ［Fields］で知っている項目を探し、その項目の［開く］から使用箇所を確認します。

ここまででAIのクレジットは消費しません。確認できる設定の範囲は、自分のkintone権限によります。

## 3. AIを使うときに、Nest Rec会員で接続する

1. Toolkitの［AI Assistant］を開き、［接続］→［接続する］を押します。
2. 開いたNest Recのページで、会員登録またはログインをします。画面が自動で開かない場合は、接続ダイアログに表示されるリンクから開きます。
3. 表示された接続先を確認し、画面の案内に沿って接続を承認します。
4. kintoneのタブへ戻り、「AIに接続済み」と利用可能なクレジットを確認します。状態が更新されない場合は［接続］→［接続を更新］で確認します。

初回10クレジットは1会員につき一度だけ、有効期限なし。支払い情報は不要で、自動課金もありません。最初に接続した1つのkintoneドメインで試せます。すでに月額契約がある場合は月間枠から先に使います。[料金・接続案内](https://www.nestrec.com/toolkit)

## 4. まず1つ、相談する

［アプリの相談］の入力欄に、知りたいことや変えたい動作を書きます。最初は、たとえば次の相談から始められます。

> このアプリの入力を楽にする改善案を1つ提案してください。今の設定と入力チェックを残し、まだコード作成や反映には進まないでください。

初めて送信する際は、送信する情報の説明を確認してください。相談文、アプリ設定、取得した登録済みJavaScript本文などをAIサービスへ送ります。

通常相談の送信は1回1クレジットです。画面に表示される消費量を確認して送ります。入力や選択だけではAIを呼びません。**Enterでも送信されるため、文章を確かめてから操作してください。**

返答と右側の案を確認し、必要なら希望を追加して相談します。2.3.6以降では、既存JSを編集する提案の「JavaScriptの変更方針」で、編集対象と理由も確認できます。

［この案で作成］は次の段階です。最終案の作成には3クレジットを使います。生成内容を確認し、利用者が反映を操作するまで、kintoneの設定やJSは変わりません。AI機能から運用環境へ直接反映することはありません。

## 一覧の変更を取り消す

2.3.17以降で動作テスト環境に反映した既存の表形式一覧1件の変更は、アプリを開き直した後も、同じブラウザーの［AI Assistant］→［これまでの反映］から取り消せます。

1. 対象の反映履歴を開き、［この反映の変更を戻す］を押します。
2. 戻す内容を確認し、［反映前の状態に戻す］を押します。

反映後に別の一覧などの設定が保存されている場合は、確認画面で理由を表示して取り消しを止めます。

## 更新するとき

1. 必要な会話・編集中コードをファイルへ保存し、処理が終わっていることを確認します。
2. 使っている版を更新します。Tampermonkey版は[公開スクリプト](https://raw.githubusercontent.com/youtotto/kintone-app-toolkit/main/kintoneAppToolkit.user.js)を開き、Tampermonkeyで更新します。ZIP版は[拡張機能版の更新手順](../extension/README.md#zip版を更新する)に沿ってファイルを置き換え、拡張機能を再読み込みします。ZIP手動導入版は自動更新されません。
3. **更新後も、使う版だけが有効か確認します。** 両方を導入済みなら、使わないToolkitをOFFのままにしてください。
4. kintoneアプリの一覧画面を再読み込みし、**「Ver 2.3.17」とToolkitのパネルが1つだけであること**を確認します。開いたままの他のkintoneタブも、再読み込みするまで旧版が動きます。

## うまく進めないとき

| 状況 | 確認すること |
| --- | --- |
| Toolkitが出ない | PCのアプリ一覧画面か、導入した拡張機能・スクリプトが有効か確認し、ページを再読み込みします。 |
| パネルが2つ出る | 使わないToolkitをOFFにして、kintoneアプリを再読み込みします。拡張機能版を使う場合は、Tampermonkey内の「kintone App Toolkit」スクリプトだけをOFFにしてください。 |
| AIが未接続 | ［AI Assistant］の［接続］から進みます。APIキーを入力する必要はありません。 |
| 接続先ページが開かない | 接続ダイアログ内のリンクを開きます。時間切れの場合は［接続する］からやり直します。 |
| 残数が足りない | ［接続］で残数と処理中の要求を確認します。無料の設定確認は引き続き使えます。 |
| 動画と表示が違う | 正式Releaseの版と自分の表示版を比較します。更新前に必要な会話・コードを保存してください。ZIP手動導入版は自動更新されません。 |
