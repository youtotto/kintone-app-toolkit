# Toolkit 2.3.2

一般配布版から、運営者が動作確認に使っていた検証専用機能を取り除きました。

- 検証環境への接続切替、検証用の費用・回数上限、検証レポートの画面を削除しました。
- 旧トークンの手入力と自動移行を削除し、Nest Rec会員の承認による接続に統一しました。
- ブラウザーに以前の検証設定が残っていても、通常の相談を妨げないようにしました。
- 本番の接続情報・会話・下書き・同意設定は引き継ぎます。契約・残クレジットは変更しません。
- 通信断後の回答回収を通常の会員接続でも利用できるように修正しました。保存済み回答を取り直すだけで、再生成・追加消費はしません。
- 検証環境の接続情報が残っている場合、その認証情報を本番へ送らず、未接続として扱います。［Nest Rec AIに接続］から接続してください。

無料の設定確認、Config Lens、フィールド・条件設定・JavaScriptの開発支援は引き続き利用できます。

更新前に作業中の会話・コードを保存し、Tampermonkeyで更新してからアプリを再読み込みしてください。

検証は外部通信を固定応答に置き換えて実施しました。今回の修正確認では実AI・実購入・実解約・kintoneへの変更を行っていません。
