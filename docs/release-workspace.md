# AI Assistantの使い方と確認範囲

## 始め方

Toolkitの基本機能は無料です。PCブラウザーにTampermonkeyとToolkitを導入し、kintoneのアプリを開いてください。取得・変更できる範囲には、操作する利用者自身のkintone権限が適用されます。

AIを使う場合はNest Recへ会員登録し、Toolkitの［接続］から同じ会員で接続します。初回10クレジットは1会員につき一度だけ、有効期限なし・自動課金なしです。支払い情報の登録は不要です。

## 設定から調べる

Fields・Views・Notices・Access Controlなどで設定を確認し、DepsやJS Scannerで参照関係を調べられます。Config Lensでは運用環境と動作テスト環境、または保存ファイルを比較できます。取得不能と設定なしを区別してください。設定の保存ファイルは、すべてを復元できるバックアップではありません。

## AIへ依頼する

- **アプリを診断**：設定やJavaScriptの不整合、確認すべき点、改善候補を整理します。
- **業務工程を読み解く**：プロセスを軸に、担当・入力・通知・アクセス制約を整理します。概要図から各工程の説明へ進めます。設定の事実・推測・根拠・確認事項を分けます。設定を確認するだけではAIを呼びません。
- **資料を作る**：概要、仕様、操作説明、引継ぎ、変更内容から目的を選びます。AIを使わない設定資料の書き出しも利用できます。
- **相談・開発**：フィールド追加、条件設定、JavaScript生成・修正などを相談できます。取得した設定と既存コードを材料にし、変更案と差分を確認してから進めます。

通知先だから担当者、編集できるから入力義務がある、とは限りません。個人別の実効権限、実際の業務、JavaScriptやプラグインの動作は別途確認してください。

## AIの利用クレジット（初回リリースの方針）

|操作|クレジット|
|---|---:|
|通常相談・仮案|1|
|資料作成|2|
|アプリ診断|3|
|業務工程の整理|10|
|最終案の作成|3|

同じ最終案のコード作成・内部修復では追加消費しません。コピー・保存・反映の操作自体は0クレジットです。月間枠は契約更新日に更新し、未使用分の繰越はありません。月間枠から先に使い、初回プレゼントの未使用分は残ります。上限を超えて自動で追加課金しません。

料金・契約条件は[Toolkitの案内](https://www.nestrec.com/toolkit)を確認してください。TEAM・Businessで共有するのは利用枠です。会話やkintoneの権限が自動共有されるものではありません。

## 変更案を反映する

相談しただけでは設定を変更しません。採用する案・生成コード・対象を確認し、動作テスト環境へ反映して実際の動作を確かめます。AI機能から運用環境へ直接反映しません。

Customizeの手編集登録やPluginsの操作、運用環境へのデプロイは別の確認操作です。アプリ全体の未反映変更が含まれることがあるため、今回の変更以外も確認してください。

## 会話と編集中の内容

会話・資料・採用内容・コード・下書きをブラウザーに自動保存します。同じアプリでAI Assistantを開くと続きが戻ります。復元中はファイル保存できません。保存状態を確認し、重要な内容は［保存した会話］の［今の内容をファイルで保存］から別途保存してください。

保存枠は同じブラウザー・ドメイン・利用者の全アプリで20 MiBです。［完了にする］から30日後に整理し、作業中と［残す］は保護します。別端末との同期はありません。ブラウザーのデータを消すと履歴も消えます。保存機能のない旧版で閉じた内容は復元できません。

## 通信が切れたとき

消費が確定した回答は、回収可能期間の30日以内であれば追加消費せず取り直せます。生成し直す操作とは区別してください。費用や終了状態が未確定の場合は、表示された状態を確認し、すぐに同じ依頼を再送しないでください。

## データの取扱い

AIへの送信には取得したアプリ設定や登録済みJavaScriptなどが含まれます。送信前の案内を確認してください。外部AI、回答回収用データ、利用・契約記録、端末内の会話は保存場所と条件が異なります。詳細は[データ取扱い・販売条件](https://www.nestrec.com/toolkit#toolkit-data)をご覧ください。
