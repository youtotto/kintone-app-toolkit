# kintone App Toolkit 2.3.8

公開日：2026年11月16日

不要・重複処理を整理し、会話画面の再描画と会話保存の負荷を減らしました。新しい機能の追加や料金・権限の変更はありません。

## 変更内容

- 呼び出されていない旧表示処理を削除し、HTMLエスケープとJSON複製の共通処理をまとめました。開発用の使用量診断は検証環境に保持し、公開本体の生成対象から外しました。
- 同じ会話画面を再表示するとき、内容と操作対象が同じなら会話・入力欄を作り直さず、フォーカスや選択範囲、スクロール位置を保持します。内容・接続状態・会話や案の版が変わったときは更新します。
- 変更がない会話の保存確認で、会話全体の繰り返しコピーと再解析を省きました。変更がある場合や保存中に追加入力した場合は、保存内容と次の保存対象を分けて保持します。
- 比較用HTMLの保持は直前の1件・最大512K UTF-16コード単位に制限し、画面終了時に解放します。大きな会話も省略せず表示します。

## 測定結果

専用Edge環境で、架空の会話200件・保存内容581,352 bytesを使い、ウォームアップを除く9回の中央値を比較しました。性能改善前の整理済みコードとの比較です。

| 対象 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 同じ画面の再描画5回 | 228.0 ms | 2.7 ms |
| 変更なし保存確認10回 | 22.8 ms | 3.4 ms |
| 内容変更後の保存1回 | 5.9 ms | 4.3 ms |

この条件では比較用HTMLの保持により使用中メモリが約0.30 MiB増え、画面終了後の増加はありませんでした。初回表示などは測定ごとの変動があり、全操作やすべての端末での高速化を示す値ではありません。実AI・ネットワーク応答時間は対象外です。[測定条件と詳細](performance-20261116.md)、[不要・重複処理の整理](refactoring-20261116.md)をご覧ください。

## 検証範囲

ユーザースクリプトと拡張機能本体に対する全146ファイルの回帰検証を実施し、それぞれ2,038件成功、失敗・タイムアウト0件を確認しています。保存中の追加入力、連続保存、完了状態、入力・表示位置の保持、同じ見た目の別会話、長文表示、送信確認の取消、古い案への操作防止を含みます。

模擬APIと隔離ブラウザーによる自動検証です。実AIの呼び出しや実kintoneへの設定反映は行っていません。今回変更していない相談・生成・反映の実機経路は、[2.3.5の検証記録](RELEASE-NOTES-2.3.5.md#検証範囲)など既存結果を引き継ぎます。Chrome本体・モバイルの実機動作を今回新たに確認したという意味ではありません。

## 更新方法

必要な会話・編集中コードを保存してから更新してください。

- 拡張機能版：[2.3.8のZIP](https://github.com/youtotto/kintone-app-toolkit/releases/download/v2.3.8/kintone-app-toolkit-2.3.8-chrome-extension.zip)を取得し、[更新手順](../extension/README.md#zip版を更新する)に従って現在のフォルダーを更新します。
- Tampermonkey版：[公開中のユーザースクリプト](https://raw.githubusercontent.com/youtotto/kintone-app-toolkit/main/kintoneAppToolkit.user.js)を開いて更新します。
- 更新後はkintoneを再読み込みし、「Ver 2.3.8」とToolkitのパネルが1つだけであることを確認します。拡張機能を使う場合、TampermonkeyのToolkitスクリプトは更新後もOFFに保ちます。

GitHubのZIP配布とChromeウェブストアの公開は別です。ストア審査中の提出版を今回のリリースに置き換える操作は行っていません。
