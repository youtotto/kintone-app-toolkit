# kintone App Toolkit 2.3.4

公開候補・未公開（2026年11月13日準備）

## 公開済み2.3.3からの変更

- 実機照合に使う KT_BUILD が2.3.2のまま残っていた問題を修正し、配布・画面表示・ビルド識別子を2.3.4にそろえます。
- ビルド時に配布版、表示版、リリースノートの一致を確認し、ビルド識別子を自動更新します。
- 公開本体に含まれている処理のソース、回帰テスト、ビルド・版更新手順を整理します。
- 同じ本体からChrome拡張機能を生成する試作用ビルドを用意します。ストア公開済みではありません。

今回の本体差分は版情報のみです。業務工程・AI相談・保存復元・JS生成の処理、料金・クレジット・契約条件は変更しません。既存機能を2.3.4の新機能として扱いません。

## 公開状態と確認範囲

現在の一般配布は2.3.3です。2.3.4のmain反映、新タグ、GitHub Release、Chromeウェブストア提出は行っていません。無料テストと実機確認は区別し、[候補の検証状況](RELEASE-CANDIDATE-2.3.4.md)に記録します。

公開前に会話・編集中コードを保存し、最終候補の更新後に画面の版とビルド識別子を実機で確認します。公開後の更新手順は公開時に案内します。
