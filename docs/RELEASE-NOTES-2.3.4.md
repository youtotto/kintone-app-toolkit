# kintone App Toolkit 2.3.4

2026年11月14日

## 変更内容

- 実機照合用のKT_BUILDが2.3.2のまま残っていた問題を修正し、配布・画面表示・ビルド識別子を2.3.4にそろえました。
- ビルド時に配布版・表示版・リリースノートの一致を検査し、ビルド識別子を自動更新します。
- 公開本体に含まれていた処理のソース、回帰テスト、ビルド・版更新手順を整理しました。

2.3.3からの配布本体の変更は版情報のみです。業務工程・AI相談・保存復元・JS生成の処理、料金・クレジット・契約条件は変更していません。

## 更新方法

1. 必要な会話・編集中コードをファイルへ保存します。
2. [公開スクリプト](https://raw.githubusercontent.com/youtotto/kintone-app-toolkit/main/kintoneAppToolkit.user.js)を開き、Tampermonkeyで更新します。
3. kintoneアプリを再読み込みし、Toolkitの表示が「Ver 2.3.4」になっていることを確認してください。

## 検証範囲

候補の無料テストは129ファイル・1,925件成功、失敗0件です。拡張機能用ビルドのチェック・生成と、両形式の129ファイルの比較も成功しています。公開する本体は、この候補と同一のファイルです。2.3.4を実際のkintoneへインストールした確認と、追加の実AI検証は行っていません。

Chrome拡張機能のビルドソースは試作です。今回の配布はTampermonkey用ユーザースクリプトで、Chromeウェブストアへの提出・公開は行っていません。
