# kintone App Toolkit 2.3.19

「商品ごとに最近の受注を見たい」と相談したとき、どのアプリの、どの項目どうしを照合するのかを仮案で確認できるようになりました。

参照先アプリや照合項目が仮案で特定できないときは、右側の［未確定の事項］に確認点が出ます。既存のルックアップから候補が見つかれば、参照先と照合項目を一緒に確認できます。

参照元を調べられなかったときは、その範囲を未確認として扱います。仮案を採用する前に、どこを確かめる必要があるかが分かります。

## 検証範囲

自社の検証用商品台帳で「商品ごとに最近の受注を見たい」と相談し、仮案に参照先の候補、商品台帳の商品コード、受注側の商品選択が表示されることを確認しました。参照元を確認できない受注アプリでは、出荷履歴を表示する相談に対し、参照先と両側の項目を尋ねる案が表示されました。

商品台帳では、新しい一覧を相談して動作テスト環境に反映し、［これまでの反映］で対象の一覧を確認しました。検証用の一覧は同じ履歴から元に戻しました。
