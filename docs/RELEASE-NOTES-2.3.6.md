# kintone App Toolkit 2.3.6

2026年11月16日

## 変更内容

- **作成前に、編集するJavaScriptと理由を確認。** AIが既存JavaScriptへの統合を選んだ場合、右側の仮案に「JavaScriptの変更方針」を表示します。編集対象のファイルとその理由を確認してから、作成へ進めます。
- 新規追加を選んだ場合も、その方針を表示します。説明のない古い会話には、推測でファイル名や理由を補いません。
- [導入から最初の相談までのガイド](getting-started.md)を追加しました。無料機能の試し方、現行のボタン名に沿ったAI接続、最初の相談例を案内します。

編集対象と理由を返すサーバー側の改善は先行反映済みです。今回は利用者側の表示を揃えます。料金・クレジット・契約条件は変更していません。

## 更新方法

必要な会話・編集中コードを保存してから更新し、kintoneアプリの一覧画面を再読み込みしてください。表示版は「Ver 2.3.6」です。

- Tampermonkey版：[公開スクリプト](https://raw.githubusercontent.com/youtotto/kintone-app-toolkit/main/kintoneAppToolkit.user.js)を開いて更新します。
- Chrome・Edge用拡張機能版：[2.3.6のZIP](https://github.com/youtotto/kintone-app-toolkit/releases/download/v2.3.6/kintone-app-toolkit-2.3.6-chrome-extension.zip)を取得し、[導入・更新手順](../extension/README.md)に沿って読み込みます。ZIP手動導入版は自動更新されません。

Tampermonkey版と拡張機能版は、どちらか一方だけを有効にしてください。

Chromeウェブストアは2.3.5が審査中です（2026年11月16日時点）。今回のGitHub公開では、審査の取り消しや2.3.6のストア提出を行っていません。
