# kintone App Toolkit 2.3.16

2026年11月26日

- 一覧の追加で並び順を指定しなかった場合、kintoneがレコード番号の降順を設定しても、Toolkitは反映成功と判定します。並び順を指定した場合は、項目・昇降順・複数項目の優先順位を照合します。
- 既存一覧の並び順だけを解除して、kintoneの既定順に戻せるようになりました。表示列などを変更する際に並び順を指定しなければ、現在の並び順を維持します。

## 検証範囲

ステージングの受注受付アプリで、一覧を並び順未指定で追加した場合の成功表示と、既存一覧の昇順を解除してレコード番号の降順に戻せることを確認しました。
